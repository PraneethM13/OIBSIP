# WebDev-L1-LandingPage — Anchorpoint

**Track:** Web Development & Designing
**Level:** Level 1 — Task 1
**Task:** Landing Page

## Overview

A static, responsive landing page for **Anchorpoint**, a fictional bouldering and rope climbing gym. Built with plain HTML5 and CSS3 — no JavaScript, no frameworks.

The design uses climbing-gym vernacular as its visual system: sections and cards are tagged with color-coded "grade chips" (e.g. `V0–V2`, `5.12+`) the same way a real route-setter marks a climb's difficulty with tape, so the color-coding actually carries meaning rather than being decorative.

## Tech Stack

- HTML5
- CSS3 (Flexbox + Grid, custom properties for theming)
- Google Fonts: Oswald (display), Inter (body), IBM Plex Mono (data/labels)
- No JavaScript

## Features

- Sticky navigation bar with 4 links (Routes, The Wall, Sends, Visit)
- Hero section with headline, subheadline, and two calls-to-action
- Three distinct content sections: Routes (features), The Wall (about), Sends (testimonials)
- Footer with placeholder contact and social links
- Consistent dark "concrete" color palette with three tape accent colors
- Fully responsive layout (CSS Grid `auto-fit` + breakpoints at 760px and 480px)
- Respects `prefers-reduced-motion`
