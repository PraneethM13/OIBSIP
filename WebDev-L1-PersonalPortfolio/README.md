# WebDev-L1-PersonalPortfolio — Praneeth Madduri

**Track:** Web Development & Designing
**Level:** Level 1 — Task 2
**Task:** Personal Portfolio

## Overview

A personal portfolio site built as a digital résumé, styled after a code editor (dark VS Code–inspired palette, tab-bar navigation, syntax-highlight colors used as the brand system). Built with plain HTML5 and CSS3 — no JavaScript required for smooth scroll (`scroll-behavior: smooth`).

## Tech Stack

- HTML5
- CSS3 (Flexbox + Grid, custom properties for theming)
- Google Fonts: JetBrains Mono (code/headers), Inter (body)
- No JavaScript

## Features

- Hero section with name, role title, and avatar placeholder
- About Me section with real career objective
- Skills section grouped into Programming / AI-ML & Web / Tools & Platforms, shown as chip grids
- Projects section with two real academic/hackathon projects (AI-Powered Smart Resume Analyzer, Food Recovery & Recycling Platform)
- Bonus Leadership & Activities section (Office Bearer role, hackathon participation)
- Contact section with email, phone, location, GitHub and LinkedIn links
- Sticky tab-bar navigation with smooth scroll to every section
- Consistent branding: one dark palette and font pairing throughout
- Fully responsive (hero and skill/project grids collapse to single column on mobile)
